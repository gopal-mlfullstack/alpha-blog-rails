# Alpha Blog

A small learning project built with **Ruby on Rails** to practice the fundamentals of Rails development.

## What I Learned

* Rails MVC structure
* Routes and controllers
* Models and validations
* CRUD operations
* Forms
* Flash messages
* Database migrations
* PostgreSQL
* ERB views
* Rails deployment

## CRUD Flow

**Create → Edit → Update → Show → Delete**
